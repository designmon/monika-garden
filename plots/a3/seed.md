# Sunlight For The Browser

I want something for the browser that brings real time back into the computer. The idea: all objects on a website cast shadows based on the actual time of day wherever I am. Not a fake light mode or dark mode, but dimensionality: daylight, angle, shadow, and a physical sense that time is passing.

The reason is emotional and practical. I spend so much time inside the computer that I lose track of the world outside. The screen becomes detached from reality. This should make the web feel lightly reconnected to the sun, so I can sense morning, afternoon, evening, and maybe notice when I have stayed too long.

## Bloom looks like

A browser extension or prototype that applies time-based shadows to webpages in a way that feels surprisingly natural, readable, and alive. It should make the browser feel less flat and less sealed away from the real day.

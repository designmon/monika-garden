# Values Compass

I want a place where I can record all my values, how I want to lead with them, and how I want to live with them. I often make decisions hard because I start reevaluating everything from scratch; I want something that helps me remember what matters to me before I spiral into rebuilding my whole worldview.

This should become a living compass: part reflection, part decision aid, part daily reminder. It should help me see the continuity between my values and my actions, so I can make choices with more steadiness and less panic.

## Updated direction

The first sprout became too form-based. I do not want this to turn into a values database, planner, or set of fields I have to maintain. Rethink it concept-first.

The core should be one strong, minimalist idea: a living compass, a bearing, a small ritual, a constellation, a daily lens, or another concept that helps me feel my values as orientation. It should propose first and ask little from me. Maybe I choose one value, one tension, one direction, or one tiny action, but I should not have to fill in a lot before it helps.

Creativity matters here. Explore what it could *be* as an experience before deciding what it stores. Pragmatic logging/reminders can come later, only if they serve the concept.

## Bloom looks like

A minimal, concept-led values companion that helps me feel a clear bearing in the moment: it proposes an orientation, a value lens, or a tiny decision ritual first, then lets me lightly steer or save what matters.

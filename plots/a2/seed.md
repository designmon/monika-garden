# Values Compass

I want a place where I can record all my values, how I want to lead with them, and how I want to live with them. I often make decisions hard because I start reevaluating everything from scratch; I want something that helps me remember what matters to me before I spiral into rebuilding my whole worldview.

This should become a living compass: part reflection, part decision aid, part daily reminder. It should help me see the continuity between my values and my actions, so I can make choices with more steadiness and less panic.

## Bloom looks like

A simple system that lets me name my values, translate them into behaviors, and receive daily reminders or prompts that make decisions feel guided instead of endlessly reopened.
